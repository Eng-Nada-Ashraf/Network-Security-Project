# 🔐 Cisco Network Security Lab

## 📌 Project Overview

This project is a Cisco Network Security lab implemented using Cisco Packet Tracer.

The lab covers different network security technologies, including:

🔥 Access Control Lists (ACLs)
🛡️ Zone-Based Firewall (ZPF)
🔒 IPsec VPN
🔑 AAA Authentication
👤 Local AAA
🔐 Layer 2 Security
🚨 Intrusion Prevention System (IPS)
🖥️ Network Management and Monitoring
🌐 Routing and Network Connectivity

## 🏗️ Network Topology

The topology contains multiple routers, switches, PCs, servers, and security zones.

### Main Network Segments

| Network          | Purpose            |
| ---------------- | ------------------ |
| 192.168.1.0/28   | R1 LAN             |
| 192.168.1.16/28  | VPN Network        |
| 192.168.1.32/28  | AAA / Management   |
| 192.168.1.48/28  | IPS                |
| 192.168.1.64/28  | Layer 2 Security   |
| 192.168.1.80/28  | Layer 2 Security   |
| 192.168.1.96/28  | DMZ                |
| 192.168.1.112/28 | Internal Network   |
| 192.168.1.128/28 | ACL Network        |
| 192.168.1.144/28 | Remote VPN Network |
